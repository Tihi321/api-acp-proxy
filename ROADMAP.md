# Roadmap

What is open for the proxy as the creative hub (`C:\projects\Personal\creative-hub`) uses it. Wiring it into Scriptorium and Book Translator is hub ticket HUB-09 (on hold). Finished work is in `.claude/tickets/` (AAP-05 ignore sampling fields, AAP-07 to AAP-10 the limits below). Fix items on a ticket branch (`AAP-NN_<what>`) cut from `master`.

## Where it stands (2026-10-22)

- **The hub's use:** an `openai-compat` provider for Scriptorium and Book Translator. The hub runs it on port 8787 (the proxy default) (it no longer needs `PROXY_IGNORE_SAMPLING`: AAP-28); see the hub's `services.json`, id `acp-proxy`.
- **AAP-05 merged, replaced by AAP-28:** `server.ignoreSampling` / `PROXY_IGNORE_SAMPLING=1` (and a settings checkbox) dropped `stream_options`, `max_tokens` and `temperature`, which both apps send and the proxy answered with 400 `unsupported_parameter`. Not yet tried with a real request (HUB-09).
- **AAP-07 to AAP-10** (stacked branches `AAP-07_json-output` → `AAP-08_stream-usage` → `AAP-09_token-limit` → `AAP-10_session-reuse`, 147 tests pass, not yet tried with a real request). They changed what the sampling drop covers: chat `stream_options` and the token limits are honoured, so only `temperature`, `top_p`, penalties, `seed` and the Responses `stream_options` are dropped. The apps' `max_tokens` now cuts answers (≈4 characters per token).
- **HUB-09 on hold** (user, 2026-10-22: "no need for now, later if needed").

## Limits seen from the hub

- [x] No JSON schema: `response_format` (chat) and `text.format` (Responses) are accepted; the agent is told the format and schema and the answer is cleaned of fences and prose. Not schema-validated, so the apps' repair step still matters. (AAP-07)
- [x] No token limit: `max_tokens` / `max_completion_tokens` / `max_output_tokens` are honoured with an estimate; the turn is cancelled and the stop is `length` / `incomplete`. (AAP-09)
- [x] No usage numbers in the stream: `stream_options.include_usage` adds the final usage chunk; usage comes from the agent, or an estimate when it reports none. (AAP-08)
- [x] Each request is a fresh agent session: opt-in `PROXY_REUSE_SESSIONS` / `server.reuseSessions` continues the session of the same conversation and sends only the new messages. (AAP-10)
- [x] Images are accepted (chat `image_url`, Responses `input_image`; PNG, JPEG, GIF, WebP; base64 or an http(s) URL the proxy downloads). (AAP-13)
- [x] Images can be generated: `POST /v1/images/generations`, Responses `image_generation` tool, chat `modalities` (Antigravity and Codex). (AAP-14)
- [x] Function calling: chat `tools` and Responses `function_call` items, through an MCP server the proxy hosts for the agents (Codex, Claude, Antigravity). (AAP-15)
- [x] Remote MCP servers: Responses `type: "mcp"` tools and `mcpServers` in the settings (http, sse, stdio), with `mcp_call` output items. (AAP-16)
- [x] Web search: chat `web_search_options` and the Responses `web_search` tool, with `web_search_call` items and `url_citation` annotations (Claude, Antigravity; Codex always searches). (AAP-17)
- [x] A harness (Claude Code, any MCP client) can ask another model: the proxy is an MCP server at `POST /v1/mcp` with `list_models`, `ask_model` (text and images, threads) and `generate_image` (saved to disk for callers on this machine); the Overview shows the address and copies the `claude mcp add` command. (AAP-23)
- [x] Many apps at once: a cap of running requests per provider (default 4, `PROXY_MAX_CONCURRENT`, per provider `PROXY_<PROVIDER>_MAX_CONCURRENT`, settings window) with a FIFO queue instead of rejections, an optional queue cap (429 `provider_queue_full`) and queue counts in `/healthz`. Running on the hub instance since 2026-10-27; merged (PR #21). (AAP-25)
- [x] Duplicate model ids in `/v1/models`: `PROXY_LIST_BARE_ALIASES=0` / `server.listBareAliases` (default on) hides the unprefixed ids so discovering clients show each model once; bare ids still work in requests. The hub sets it to 0. (AAP-26)
- [x] App-driven agent loops: the plain prompt preamble no longer says "text-only" or "do not use tools" (codex refused JSON-action prompts with "I can't use tools in this text-only request"); it forbids only the agent's own shell, files, web and permission requests and tells it to produce described actions or JSON as text. (AAP-27)
- [x] Sampling fields no longer break clients: chat `temperature`, `top_p`, `presence_penalty`, `frequency_penalty`, `seed`, `logit_bias` and Responses `temperature`, `top_p`, `stream_options` are always accepted and dropped (Scriptorium sent `temperature: 0.2` and got a 400); chat `n: 1` is accepted. The dropped names are in the `x-acp-proxy-ignored-params` response header and the Recent requests table. `PROXY_IGNORE_SAMPLING` / `server.ignoreSampling` removed. (AAP-28)
- [x] Usage per provider (persisted totals, plan limits for Codex and Claude) and a redesigned settings window with a sidebar. (AAP-29)
- [x] Per-provider prompt size limit: Antigravity prompts over 180,000 characters (the agent silently cuts at ~192,000) are refused with a 400 `context_length_exceeded`; setting `providers.<id>.maxPromptChars`, `max_prompt_chars` in `/v1/models`. (AAP-30)
